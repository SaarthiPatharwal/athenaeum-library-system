Privacy Policy

Last updated: July 2026

1. Overview

Athenaeum is a demonstration library management interface built as part of an academic course project. This page explains, in plain terms, what happens to information entered into the Service.

2. What data is collected

Data enteredWhere it goes
Book records (title, author, ISBN, quantity)Held only in your browser's memory for the current session
Sign-in / sign-up form fieldsNot transmitted or stored anywhere — the flow is simulated
Analytics or tracking cookiesNone are used by this project

Because this is a static, front-end-only demonstration, nothing you type into any form is sent to a server or saved permanently — refreshing the page resets all in-session data.

3. Why this matters for you

You should not enter real passwords, real personal details, or any sensitive information into this demo. Treat every field as a placeholder for illustrating how the interface behaves, not as a real account system.

4. Third-party services

This project loads fonts from Google Fonts. No other third-party analytics, advertising, or tracking services are integrated into the Service.

5. Children's privacy

This Service is not directed at children and does not knowingly collect any data, from anyone, given its demonstration nature described above.

6. Changes to this policy

This policy may be updated as the project evolves for course requirements. Any changes will be reflected on this page.

7. Contact

Questions about this project can be directed to its author, Saarthi Patharwal, in the context of the course submission it was created for.
